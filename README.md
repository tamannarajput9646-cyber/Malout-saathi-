# Malout Sathi - Kisan Sahayak App

Malout Sathi is a digital companion for the farmers of Malout, Punjab.

Features:
- Daily Mandi Bhav (Malout & Nearby Mandis)
- Mausam / Weather Forecast
- Kheti-Badi Tips & Techniques
- Sarkari Yojana Updates for Kisans
- Expert Salah

Made for Malout ke Kisans.
Built by Tamanna.
